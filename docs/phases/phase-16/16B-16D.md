Phase 16 Implementation Plan: Multi-Provider Chat & UI
Goal
Enable users to switch between LLM providers (Anthropic, OpenAI, etc.) while maintaining full RAG capabilities (tool use) and improving the UI with streaming responses.

User Review Required
IMPORTANT

Decision on Phase 16B/D Strategy: We are proceeding with Option 2 (Full Tool Support).

Why? Shipping "Basic Chat" for OpenAI (Option 1) would break the core RAG functionality (searching docs), resulting in a degraded user experience.
Impact: Phase 16B will be slightly larger as it will include the OpenAIProvider and its tool-loop implementation (effectively pulling Phase 16D forward).
Refactoring: 
agent.ts
 will be refactored to use a ChatProvider interface. The manual loop logic for OpenAI will live inside the OpenAIChatProvider, while AnthropicChatProvider will continue to leverage the optimized Claude SDK query() method.
